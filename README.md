# Tribute Page – Dr. A.P.J. Abdul Kalam

A responsive single-page tribute website dedicated to **Dr. A.P.J. Abdul Kalam**, created as part of the Web Development Track at Veda Technology.

## 📌 About the Project

This project is a static tribute page that highlights the life, achievements, and important events in the life of Dr. A.P.J. Abdul Kalam.

The page includes:

- Dr. A.P.J. Abdul Kalam's image
- Biography
- Achievements
- Timeline
- Responsive design for mobile and desktop
- Clean and simple layout

## 🛠️ Technologies Used

- HTML5
- CSS3
